# AGENTS.md

## 프로젝트 구조

- `index.html`: 페이지의 HTML 구조와 콘텐츠를 관리한다.
- `style.css`: 모든 시각적 스타일과 반응형 디자인을 관리한다.
- `script.js`: 메뉴 데이터와 추천 동작을 관리한다.

## 작업 규칙

- HTML, CSS, JavaScript의 책임을 위 구조대로 분리한다.
- 인라인 스타일을 사용하지 않고 모든 스타일은 `style.css`에 작성한다.
- 메뉴는 `script.js`의 기존 `koreanMenus` 배열에만 추가한다.
- 기존 주황/크림 색상, 둥근 카드와 버튼 등 현재 디자인 흐름을 유지한다.
- 외부 라이브러리나 프레임워크를 추가하지 않고 순수 HTML, CSS, JavaScript를 사용한다.
- 필요한 부분만 작게 수정하고 기존 동작과 접근성 속성을 보존한다.

## 완료 확인

- 브라우저에서 메뉴 추천 버튼을 여러 번 눌러 기존 추천 기능이 정상 동작하는지 확인한다.
- 콘솔 오류와 모바일 화면의 잘림 또는 넘침이 없는지 확인한다.
