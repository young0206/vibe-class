# 결제 규칙

## 환불 수수료

- 환불 수수료율은 원 결제 금액의 5%다.
- 모든 금액은 최소 화폐 단위(minor unit)의 정수로 계산하고 저장한다.
- 수수료가 정수로 나누어떨어지지 않으면 소수 부분을 버림한다.
- 실제 환불액은 `원 결제 금액 - 환불 수수료`로 계산한다.
- 원 결제 금액, 수수료, 실제 환불액과 통화를 각각 명확히 구분한다.

## 검증

- 주문 객체가 반드시 있어야 한다.
- 환불 금액은 0보다 큰 안전한 정수여야 한다.
- 통화 값이 없으면 `KRW`를 사용한다.
- 계산된 수수료와 실제 환불액도 안전한 정수인지 확인한다.

## 에러 처리

- 주문 객체가 없거나 금액 형식이 잘못되면 `TypeError`를 발생시킨다.
- 금액이 0 이하이거나 계산 결과가 유효 범위를 벗어나면 `RangeError`를 발생시킨다.
- 검증에 실패한 환불은 처리하거나 성공 로그를 남기지 않는다.
- 성공한 환불 로그는 `lib/logger.js`의 `logPayment()`만 사용하며 주문 ID, 원 결제 금액, 수수료, 실제 환불액, 통화와 상태를 구조화해 기록한다.
