# Page Check

HTML 파일을 읽기 전용으로 검사하고 한국어로 결과를 보고한다.

## 실행

1. 사용자가 지정한 HTML 파일을 찾는다. 지정하지 않았다면 현재 작업 범위의 `index.html`을 우선 사용한다.
2. 다음 명령을 실행한다.

   ```bash
   python3 <skill-directory>/scripts/page_check.py <html-file>
   ```

3. 스크립트 결과를 근거로 간결하게 보고한다. 파일을 수정하지 않는다. 수정 요청도 함께 받은 경우에만 별도로 수정한다.

## 검사 기준

- 🔴심각: `<title>`이 없거나 비어 있음, 존재해야 할 내부 링크 대상이 없음, UTF-8 선언이 없거나 한글 파일이 UTF-8로 해석되지 않음
- 🟡주의: `<img>`의 `alt`가 없음, 모바일 viewport 메타가 없거나 `width=device-width`를 포함하지 않음
- 🟢제안: 다섯 항목이 모두 통과했음을 알리거나, 실패는 아니지만 품질을 더 높일 선택적 개선안을 제시함

내부 링크 검사 시 `http:`, `https:`, `mailto:`, `tel:`, `data:`, 프로토콜 상대 URL(`//`)은 외부 링크로 제외한다. 로컬 파일 경로와 같은 문서 안의 `#fragment`는 검사한다.

## 보고 형식

먼저 검사한 파일과 요약 건수를 쓰고, 발견 사항을 심각도 순서(🔴, 🟡, 🟢)로 나눈다. 각 항목에 검사 관점, 근거가 되는 줄 번호, 문제와 권장 조치를 포함한다. 문제가 없는 관점도 통과 여부가 드러나게 요약한다.

스크립트가 파일 읽기 실패나 HTML 파싱 불가를 보고하면 추측하지 말고 해당 오류를 🔴심각으로 전달한다.
