# AGENTS.md

이 문서는 이 프로젝트에서 작업하는 AI 에이전트가 따라야 할 지침입니다.

## 언어

- 항상 한국어로 답변합니다.
- 코드 주석은 한국어로 작성합니다.
- HTML, CSS, JavaScript 문법과 API 이름은 원문을 유지합니다.

## 스타일

- 설명은 간결하고 단계별로 합니다.
- 기존 코드 스타일을 유지합니다.
- 위험한 명령이나 파일 삭제 전에는 반드시 사용자에게 확인을 받습니다.

## Overview

이 프로젝트는 HTML과 CSS를 활용하여 나의 취미를 소개하는 웹페이지입니다.

주제는 **프로야구 관람**이며, 가장 좋아하는 팀은 **한화 이글스**입니다.

## 목표

- 깔끔하고 보기 좋은 취미 소개 페이지를 제작합니다.
- 반응형 레이아웃을 적용합니다.
- HTML 시맨틱 태그를 적극 활용합니다.
- CSS는 읽기 쉽고 유지보수하기 쉽게 작성합니다.
- JavaScript는 꼭 필요한 경우에만 사용합니다.

## 페이지 구성

다음 내용을 포함합니다.

- 메인 소개(Hero)
- 나의 취미 소개
- 한화 이글스를 좋아하는 이유
- 좋아하는 선수 또는 응원 포인트
- 야구 경기 직관 사진 또는 이미지 영역
- 응원 문구 및 마무리

## 디자인

- 메인 컬러는 주황색, 흰색, 네이비 계열을 사용합니다.
- 카드 형태의 레이아웃을 적극 활용합니다.
- 너무 복잡하지 않고 깔끔한 디자인을 우선합니다.
- 모바일에서도 보기 좋도록 반응형으로 구현합니다.

## 작업 원칙

- 기존 파일을 불필요하게 수정하지 않습니다.
- 변경 사항은 최소 범위로 적용합니다.
- 작업 후 결과를 검증합니다.
- 커밋 전 변경 사항을 간단히 요약합니다.
